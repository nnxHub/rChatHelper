**rChatHelper** — мощный и минималистичный клиентский мод для комфортной работы с игровым чатом Minecraft на версии **Fabric 1.21.11**.

Мод спроектирован специально для игроков, лидеров кланов и модераторов: он добавляет свободное выделение любого текста мышкой, умную заморозку чата, быстрый ответ в один клик и удобное контекстное меню с готовыми шаблонами наказаний и разбана игроков.

---

## 🔥 Основные возможности

### 1. Свободное выделение текста (ЛКМ)
- Плавное посимвольное выделение любого фрагмента текста в чате без ограничений.
- Поддержка выделения сообщений с префиксами, ссылками, координатами и никнеймами.
- Мгновенное копирование выделенного фрагмента в буфер обмена (`Ctrl + C` или через контекстное меню).

### 2. Умная заморозка чата (Chat Freeze)
- При зажатии ЛКМ для выделения или при открытии контекстного меню чат мгновенно замирает на месте.
- Новые входящие сообщения с сервера не сдвигают строки под курсором — вы никогда не промахнетесь мимо нужного сообщения в активном потоке чата.
- После снятия выделения или закрытия меню чат плавно возвращается в актуальное состояние.

### 3. Быстрый ответ (Ctrl + ЛКМ)
- Нажмите `Ctrl + Клик` по никнейму игрока в любом сообщении — мод мгновенно подставит `!<ник> ` в строку ввода для быстрого ответа в глобальный чат.

### 4. Контекстное меню по правому клику (ПКМ)
Кликните правой кнопкой мыши по любому сообщению в чате, чтобы открыть удобное всплывающее меню:
- **Наказания игрока**:
  - `Бан` (`/ban` / `/tempban`)
  - `Бан по IP` (`/banip` / `/tempbanip`)
  - `Мут` (`/mute` / `/tempmute`)
- **Снятие наказаний**:
  - `Разбан` (`/unban`)
  - `Разбан по IP` (`/unbanip`)
  - `Размут` (`/unmute`)
- **Копирование**:
  - `Копировать полностью` — всё исходное сообщение целиком
  - `Копировать текст` — чисто текст без префиксов
  - `Копировать выделенное` — только выделенный мышкой фрагмент
- **Взаимодействие**:
  - `Ответить в чате` (`!<ник> `)
  - `Ответить в ЛС` (`/msg <ник> `)
  - `Игнорировать` (`/ignore <ник>`)

### 5. Интерактивное меню наказаний и разбана
- **Автоматическая подстановка ника**: кликнули по сообщению — ник нарушителя уже в поле ввода.
- **Гибкая настройка времени**:
  - Быстрые кнопки пресетов времени: `15m`, `30m`, `1h`, `3h`, `12h`, `1d`, `3d`, `7d`, `30d`.
  - Кнопка быстрой очистки времени (`✕`).
  - Если поле времени пустое — команда автоматически переключается на постоянное наказание навсегда (`/ban`, `/mute`, `/banip`).
  - При вводе времени команда автоматически переключается на временное (`/tempban`, `/tempmute`, `/tempbanip`).
- **Поле причины**:
  - Необязательное поле. Если причина не указана — команда отправляется без причины.
- **Компактное меню разбана / размута**:
  - Отдельное меню для `/unban`, `/unbanip`, `/unmute` с возможностью указать причину снятия наказания и кнопкой подтверждения.
- **Живое превью команды**:
  - Перед отправкой вы в реальном времени видите итоговую команду, которая пойдет на сервер (например: `/tempban Steve 3d 1.1 Читы`).

### 6. Тёмный эргономичный UI
- Стильный интерфейс в глубоких тёмных тонах (`#121214`), без лишнего визуального шума.
- Идеально вписывается в ванильный дизайн Minecraft и кастомные ресурспаки.

## 📦 Установка

1. Установите **Fabric Loader** для Minecraft **1.21.11**.
2. Установите **Fabric API** для 1.21.11 в папку `.minecraft/mods`.
3. Скачайте файл **`rChatHelper-1.0.0.jar`** из этого репозитория (или вкладки [Releases](https://github.com/nnxHub/rChatHelper/releases)).
4. Поместите `rChatHelper-1.0.0.jar` в папку `.minecraft/mods`.
5. Запустите игру и наслаждайтесь удобным чатом!
